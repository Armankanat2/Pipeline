# A-47 Hazard Image Prompt v0.1

## Target
Sdelat controlled edit tolko ot predostavlennogo referens-izobrazheniya klinovykh lesov dlya slide `A-47`.

## Obazatelno skazat modeli
- Ispolzuy imenno predostavlennoe izobrazhenie kak bazu.
- Ne menyay kameru, perspektivu, fon, material i tip lesov bez pryamogo ukazaniya.
- Ne pererisovyvay sistemu zanovo.
- Iskazhat krepezhnye elementy, uzly i detali mozhno tolko v predelakh opisannykh izmeneniy.
- Itog dolzhen ostatsya tekhnicheski chitayemym uchebnym foto/renderom na belom fone.

## Prompt
EDIT THE PROVIDED REFERENCE IMAGE ONLY. Use the provided wedge-lock scaffold image as the base image and preserve its overall perspective, white background, metallic material appearance, lighting, and main scaffold geometry. This is an educational safety visual. Do not replace the scaffold with a different design. Do not invent a new camera angle. Do not stylize. Keep it photorealistic and as close to the provided reference as possible.

Apply only these controlled changes:
1. Remove the lower staircase completely so there is no safe lower access.
2. Remove all diagonal braces in the lower level.
3. On the second working level, remove part of the decking so the platform is incomplete and visibly unsafe.
4. On the second level, on one side, remove the side guardrails so the upper level has missing side protection.

Important constraints:
- Keep all remaining scaffold components realistic for wedge-lock scaffolding.
- Do not distort or redesign fittings, locking points, posts, ledgers, or remaining parts beyond the requested edits.
- Keep the image suitable for technical training: clear, readable, white background, no workers, no extra objects, no text, no arrows, no labels.
- Show all four hazards clearly in one image.
- The final image should look like a real scaffold render/photo that has been modified to contain these safety defects.
