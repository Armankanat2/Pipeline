# Preflight Checklist Template v1

## Naznachenie

Cheklist nuzhen dlya finalnoy proverki release-grade paketa pered peredachey vo vneshniy production kontur.

## 1. Files

- Vse finalnye fayly nazvany po release-pravilu
- V release net sluchaynykh dubley i nefinalnykh draftov
- Versii v release note sovpadayut s fakticheskimi faylami

## 2. Text and layout

- Net bitoy kodirovki
- Net sluchaynykh smesey alfavitov
- Net yavnykh opechatok v release-grade faylakh
- Numeratsiya stranits i listov proverena

## 3. Assets and rights

- Po klyuchevym assetam ponyaten rights-status
- V release net blocked-assets
- Client-provided brand-assets identifitsirovany
- Linked-assets ne poteriany

## 4. Fonts and exports

- Spisok shriftov sobran
- Ponyatno, mozhno li peredavat font files
- Print-ready eksport proveren
- Digital-ready eksport proveren

## 5. Print and digital

- Print-safe parametry provereny po print production spec
- QR na pechati provereny, esli est
- Direct links rabotayut, esli est
- Testovaya pechat provedena, esli nuzhna

## 6. Reshenie

- Preflight proyden: `yes / no`
- Print-ready: `yes / no / partial`
- Digital-ready: `yes / no / partial`
- Rights-cleared: `yes / no / partial`
- Fonts-confirmed: `yes / no / partial`
