# Bottleneck Register Template v1

## Naznachenie

Reestr uzkikh mest nuzhen, chtoby `Pipeline` fokusirovalsya na ogranichivayushchikh faktorakh, a ne na samykh shumnykh ili samykh krasivykh zadachakh.

## Reestr

| ID | Data | Zona | Simptom | Dokazatelstvo | Uroven vliyaniya | Tekushchiy fokus | Deystvie | Owner | Status |
|---|---|---|---|---|---|---|---|---|---|
| BOT-01 | YYYY-MM-DD | `sources / architecture / script / assets / qa / release / template / process` |  |  | `local / module / course / pipeline` | `yes / no` |  |  | `open / monitoring / mitigated / closed` |

## Pravilo prioriteta

V aktivnom fokuse dolzhny ostat'sya tolko `1-2` uzkikh mesta s naibolshim effektom na progress ili quality.
