# Task Board Template v1

## Naznachenie

Shablon opisivaet minimalnuyu strukturu production board dlya vedeniya kursov v rabote.

## Kolonki doski

- `Backlog`
- `Intake`
- `Research`
- `Design`
- `Production`
- `QA`
- `Pilot`
- `Release`
- `Archive`

## Kartochka kursa

Kazhdaya karta dolzhna soderzhat:

- Nazvanie kursa:
- Kod kursa:
- Tekushchiy stage:
- Owner:
- Prioritet:
- Deadline:
- Soglasuyushchiy:
- Format kursa:
- Sledushchiy artefakt:
- Status gate:
- Poslednee obnovlenie:

## Minimalnyy checklist karty

- Brief sozdan
- Istochniki sobrany
- Job map gotova
- Outcomes zafiksirovany
- Arkhitektura kursa sobrana
- Script napisan
- Assets sobrany
- Draft deck gotov
- QA proyden
- Test sobran
- Pilot proyden
- Release podgotovlen

## Status gate

Rekomenduemye statusy:

- `not started`
- `in progress`
- `pass`
- `revise`
- `blocked`
- `released`
