# Worker Materials

Syuda kladutsya A3-stendovye instruktsii i drugie pechatnye metodicheskie materialy dlya rabochikh.

Ozhidaemye fayly:

- `12_worker_instruction_v1.0.pdf`
- `12_worker_instruction_v1.0.pptx`
- `12_worker_instruction_v0.2.md`
- `12_worker_instruction_extra_v1.0.pdf` pri dopolnitelnom zaprose klienta
- `12_worker_instruction_extra_v1.0.pptx` pri dopolnitelnom zaprose klienta

Materialy v etoy papke dolzhny:

- povtoryat brand shell zakazchika;
- sobirat bazovoe posobie `1-5` listov na osnove tem iz prezentatsii;
- pri nepolnykh dannykh formirovat spisok utochnyayushchikh voprosov;
- pri neobkhodimosti podderzhivat dopolnitelnoe rasshirennoe posobie;
- byt gotovymi k pechati i laminatsii;
- pokryvat logiku `pered rabotoy / vo vremya raboty / posle raboty / chego delat nelzya`;
- imet numeratsiyu stranits;
- pri neobkhodimosti podderzhivat `QR-ready` sloty.
